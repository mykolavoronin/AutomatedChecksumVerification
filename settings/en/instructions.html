Enable automatic checksum verification

  1. Open chrome://extensions.
  2. Find Automated Checksum Verification and open Details.
  3. Enable Allow access to file URLs.
  4. Reload the publisher's download page, then download your file.

The extension reads the completed local download and compares its checksums with the publisher's values. Files are never uploaded.

You can also open the extension popup and choose a file manually. A checksum match verifies integrity against a supplied digest; it does not prove a file is safe or authenticate its publisher.
